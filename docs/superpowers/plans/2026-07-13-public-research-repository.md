# Better Router Adaptive Public Research Repository Plan

**Goal:** Publish a reproducible, privacy-preserving study of learned multi-LLM routing.

**Architecture:** Maintain a standalone Python research package. Benchmark processing, model training, online replay, evaluation, and publication artifacts communicate through versioned files and immutable run manifests. Production Better Router integration is excluded.

## Global constraints

- Four model arms and four task groups in the primary experiment.
- XGBoost and disjoint LinUCB are the two AI algorithms.
- Deterministic routing is a baseline; the oracle is an upper bound.
- Public or explicitly synthetic data only.
- Seeds are `42`, `123`, `2026`, `31415`, and `271828`.
- Results are generated by scripts and never entered manually.
- Every phase requires tests, evidence, review, and a focused commit.

## Tasks

1. Reproducible package and strict configuration.
2. Dataset acquisition, provenance, licensing, and checksums.
3. Cleaning and canonical long-format schema.
4. Leakage-safe feature engineering and prompt-level splits.
5. Utility, deterministic baseline, and oracle.
6. XGBoost router with validation-only tuning.
7. Disjoint LinUCB with prequential replay.
8. Metrics, paired bootstrap, sensitivity analysis, and figures.
9. End-to-end pipeline and immutable run manifests.
10. IEEE report, poster, website article, and submission verifier.
