**Better Router Adaptive** is a reproducible research project that studies whether learned routing policies can improve multi-LLM model selection under combined quality, cost, latency, and reliability objectives.

The academic experiment compares:

1. an XGBoost utility predictor;
2. a disjoint LinUCB contextual bandit;
3. a deterministic Better Router proxy baseline;
4. an offline oracle upper bound.

This repository is independent from the Better Router production runtime. It does not store production prompts, responses, API keys, user identifiers, or organization identifiers.

## Research question

> Can learned routing policies achieve higher expected utility than a deterministic weighted policy when selecting among heterogeneous language models?

The primary utility function is:

\[
U = 0.65Q - 0.20C_n - 0.10L_n - 0.05E
\]

where `Q` is normalized quality, `C_n` normalized cost, `L_n` normalized latency, and `E` an error indicator.

## Reproducibility policy

- Prompt-level splits prevent train/test leakage.
- The seeds are fixed to `42`, `123`, `2026`, `31415`, and `271828`.
- Test fixtures are synthetic and are never presented as experimental evidence.
- Result values will be generated by scripts rather than typed into the paper.
- Every experiment run will include its configuration, environment metadata, hashes, and Git commit.

## Repository relationship

This study is motivated by the intelligent routing subsystem of Better Router. The production system remains separate; integration of learned policies is explicitly future work and requires an independent safety and deployment review.
